## 👤 Criador e Histórico
Este projeto foi idealizado e desenvolvido por **Adiel Santos Fontes**, um desenvolvedor de software com vasta experiência em tecnologias modernas e legadas.

*   **Criador:** Adiel Santos Fontes
*   **Data Inicial do Projeto:** Setembro de 2011

O **Bioghet-Orcamento** é um sistema de gestão empresarial que demonstra a solidez da plataforma **ASP.NET (C#)**, mantendo-se funcional e organizado ao longo de mais de uma década de evolução técnica.

## 🚀 Funcionalidades Principais
- **Gestão de Vendas:** Módulos completos para emissão e acompanhamento.
- **Financeiro:** Controle de pagamentos, faturamento e fluxo de caixa.
- **Módulo de Orçamentos:** Interface dedicada para criação e edição de orçamentos técnicos.
- **Relatórios:** Consultas detalhadas e extração de dados para tomada de decisão.
- **Segurança:** Sistema de login estruturado com níveis de acesso.

## 🛠️ Stack Técnica
- **Linguagem:** C#
- **Framework:** ASP.NET Web Forms
- **Configuração:** Gerenciamento via `Web.config`.
- **Organização:** Estrutura modular dividida por pastas de responsabilidade (Vendas, Pagamento, Relatorios).

## 📂 Organização do Projeto
*   `/Vendas`: Processamento de pedidos e vendas.
*   `/Pagamento`: Lógica financeira e liquidação.
*   `/Relatorios`: Consultas e exportação de dados.
*   `/App_Code`: Núcleo da lógica de negócio e classes de suporte.
*   `/App_Themes`: Definições visuais e estilos do sistema.
